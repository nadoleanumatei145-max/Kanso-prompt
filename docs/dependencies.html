Dependencies

Six requirements, none of them heavy.

Kanso is a small C++ binary. It links against Lua and vendors two header-only libraries. Everything else ships with your compiler. Here is exactly what you need, per distribution, and how to get it.

Requirements

What Kanso needs to build and run.

  • C++17 compiler build g++ 9+ or clang++ 10+. Any recent version works.
  • git build To clone the repo and vendor the header-only dependencies.
  • Lua 5.3+ runtime Development headers and shared library. 5.4 recommended.
  • sol2 build Header-only C++ ↔ Lua binding. MIT. By ThePhD.
  • nlohmann/json build Header-only JSON parser. MIT. By Niels Lohmann.
  • zsh runtime Any version with prompt_subst. That's all modern zsh.

System packages

Install per distribution.

Most package managers cover everything except sol2, which only Arch (via AUR) packages. The build step below vendors sol2 either way, so skip it if you already have it installed system-wide.

Arch Linux

shell
sudo pacman -S --needed base-devel git lua nlohmann-json

# sol2 is in the AUR
yay -S sol2

Debian / Ubuntu

shell
sudo apt update
sudo apt install -y build-essential git \
  liblua5.4-dev nlohmann-json3-dev

Fedora

shell
sudo dnf install -y gcc-c++ git \
  lua-devel nlohmann-json-devel

openSUSE

shell
sudo zypper install -y gcc-c++ git \
  lua-devel nlohmann-json-devel

Build

Clone, compile, install.

The vendor step pulls the two header-only libraries into ./vendor/. Skip it if you installed them from your package manager.

shell
# 1. Clone the repo
git clone https://github.com/nadoleanumatei145-max/Kanso-prompt.git
cd Kanso-prompt

# 2. Vendor the header-only dependencies
#    (skip if sol2 / nlohmann-json are installed system-wide)
mkdir -p vendor
git clone --depth 1 https://github.com/ThePhD/sol2.git vendor/sol2
git clone --depth 1 https://github.com/nlohmann/json.git vendor/json

# 3. Compile
g++ src/main.cpp -o prompt_renderer -std=c++17 -O2 \
  -I vendor/sol2/include \
  -I vendor/json/single_include \
  -llua

# 4. Install
sudo mv prompt_renderer /usr/local/bin/

If you have sol2 and nlohmann/json installed system-wide, drop the two -I flags. On Debian-based systems the Lua library may be -llua5.4 instead of -llua — check with pkg-config --list-all | grep lua.

Verify

Make sure it runs.

Pass an exit code and a duration as arguments. Kanso prints a formatted prompt line to stdout.

shell
prompt_renderer 0 0.5
