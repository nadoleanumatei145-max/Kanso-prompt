Prompt renderer for zsh

A prompt that stays out of the way.

Kanso renders your zsh prompt from a JSON config and a Lua script — directory, git branch, execution time, exit code, and whatever else you script. Inspired by oh-my-zsh and Starship, built as one small C++ binary.

What it does

Four modules built in. As many as you want after that.

Kanso ships with the pieces most prompts end up reimplementing, and hands the rest of the prompt over to a small Lua API.

01

Modules that are already there

Location, git branch, execution time, and an exit-code arrow ship with the binary. Each one has an enable flag, an icon, and a 256-color code in your JSON config.

02

Custom modules in Lua

gui.add_module takes an icon, a color, and a value — either a string, or a function evaluated on every prompt. Run a command with exec() and drop its output straight into the prompt.

03

Config with sane fallbacks

kanso.json is optional. Every key falls back to a default, so a missing file or a half-written config still renders a complete prompt.

04

Native output, no middleware

Kanso prints zsh's own %F{…} color escapes. No prompt theme loader, no shell-side substitution tricks, no chain of subprocesses behind every segment.

Configuration

Tune it in JSON.

Everything lives in ~/.config/kanso/kanso.json. Missing keys fall back to the defaults below, so you only write what you want to change. Set newline to false to keep the arrow on the same line as the modules.

kanso.json 
{
  "location_module": true,
  "location_icon": " ",
  "location_color": "33",

  "git_status_module": true,
  "git_status_icon": " ",
  "git_status_color": "171",

  "duration_module": true,
  "duration_icon": "󰔛 ",
  "duration_color": "214",

  "arrow": true,
  "arrow_icon": "󰘍 ",
  "arrow_color_succes": "76",
  "arrow_color_fail": "196",

  "newline": true
}

Scripting

Write the rest in Lua.

Custom modules are appended in the order you add them. Give each one an icon, a color, and a value — a string, or a function that runs every time the prompt is drawn.

exec(cmd)
Runs a shell command and returns its trimmed output.
exit_code
Exit status of the last command.
duration
Duration of the last command, in seconds.
current_dir
Working directory, with $HOME shortened to ~.
branch
Current git branch, or an empty string outside a repository.
newline
Whether a line break is printed before the arrow. Can be overridden from Lua. Default: true.
kanso.lua 
-- ~/.config/kanso/kanso.lua

gui.add_module({
  icon  = " ",
  color = "141",
  value = function()
    return exec("node --version")
  end
})

gui.add_module({
  icon  = " ",
  color = "76",
  value = exec("whoami")  -- run once, at load
})

-- optional: keep the arrow on the same line
-- newline = false

Install

Build it, hook it, forget about it.

Clone, vendor the two header-only libraries, compile, and drop the binary in your path. Full per-distribution instructions live on the dependencies page.

01 — Clone & build

shell 
git clone https://github.com/nadoleanumatei145-max/Kanso-prompt.git
cd Kanso-prompt

mkdir -p vendor
git clone --depth 1 https://github.com/ThePhD/sol2.git vendor/sol2
git clone --depth 1 https://github.com/nlohmann/json.git vendor/json

g++ src/main.cpp -o prompt_renderer -std=c++17 -O2 \
  -I vendor/sol2/include \
  -I vendor/json/single_include \
  -llua

sudo mv prompt_renderer /usr/local/bin/

02 — Add to ~/.zshrc

zsh 
# ~/.zshrc
setopt prompt_subst
zmodload zsh/datetime

preexec() { CMD_START=$EPOCHREALTIME }

set_custom_prompt() {
  local last_status=$?
  local duration=0
  if [ -n "$CMD_START" ]; then
    duration=$(printf "%.3f" $(( EPOCHREALTIME - CMD_START )))
    unset CMD_START
  fi
  PROMPT_TEXT=$(/usr/local/bin/prompt_renderer $last_status $duration)
}

autoload -Uz add-zsh-hook
add-zsh-hook precmd set_custom_prompt

PROMPT='$PROMPT_TEXT'

The second argument is the duration of the last command in seconds. Leave it out and the timing module stays hidden.
